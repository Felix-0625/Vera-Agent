# 落地页实录脚本

本轮新增功能适合用一条真实任务串起来：接任务 → 审批 → 修改 → 测试 → 核对执行记录 → 保存并召回项目记忆 → 查看受控改进。建议先做一支 **90 秒产品片**，另保留 **3–5 分钟完整实录**供文档或发布说明引用。下表时间是剪辑目标，实际模型等待时间可加速，但应标明倍速或省略等待。

## 录制前准备

1. 使用独立演示项目、演示会话与配置目录；使用合成代码和任务，窗口中不出现真实项目、私人路径或 API Key。模型配置在开录前完成，录制期间不打开凭据页。
2. 准备一个小型计算器项目：`add(a, b)` 暂时写成 `a - b`，已有失败的单元测试。开始前亲自运行测试确认红灯；不要用随机复杂任务做第一条演示。
3. 接入真实模型，权限设为需要审批文件修改与终端命令。预先验证本机能完成测试；真实录制时保留工具请求、批准、测试退出码与最终改动。
4. 准备一条项目记忆，例如“本项目测试使用 python -m unittest -q，修改后运行全部测试”。在另一条新会话中演示召回，确认项目作用域正确。
5. 改进提案段单独录制。Critic/评测会产生费用，可提前跑完，再录报告。保留模型、用例数量、重复次数和结果；若为 `no_difference` 或未推荐，就真实展示“未采纳”。不要将手工插入的推荐状态描述成真实门禁通过。
6. 关闭通知，固定窗口大小、缩放、主题和侧栏宽度。先录 10 秒，检查小字、光标、声音和边缘裁切，再开始正式录制。

## 90 秒分镜与操作

| 时间 | 画面与真实操作 | 字幕 / 旁白 |
| --- | --- | --- |
| 0–6 s | 工作站全貌，绑定“演示计算器”项目 | 把任务、工具与结果放进一个本地工作站。 |
| 6–16 s | 输入下面的修复任务，发送给真实模型 | 从一个能复现的问题开始。 |
| 16–30 s | 展开工具请求，阅读内容后点击批准；展示文件改动 | 关键操作先确认，工具结果可核对。 |
| 30–42 s | 测试从失败到通过；停留在命令、退出码和 diff 上 | 修改有没有用，看实际验证结果。 |
| 42–55 s | 打开“执行记录”，展开本轮工具 span、verification、outcome | 每轮执行都有记录，评分依据可追溯。 |
| 55–69 s | 打开“长期记忆”，显示项目作用域；新会话询问测试约定 | 项目约定可以保存、检索和追溯版本。 |
| 69–83 s | 展示已有的真实提案与评测报告，说明推荐或未推荐原因 | 改进先评测，通过后仍由你决定是否采纳。 |
| 83–90 s | 回到项目与最终修改，结尾显示仓库和快速开始 | VeraAgent，你的个人工作站。 |

可以直接粘贴的任务：

```text
请修复计算器的 add 函数。先运行现有测试确认问题，再做最小修改，最后重新运行全部测试。
不要修改测试来迎合实现，不要安装依赖。需要修改文件和执行终端命令时先等我确认。
完成后说明改了什么，并给出实际执行的测试命令和结果。
```

完整版本额外保留：失败测试全文、审批内容、完整 diff、新会话记忆召回；组织/工作流另录一段 30–45 秒补充素材，展示模板 → 实例 → 串行运行 → Supervisor 回传。避免在 90 秒主片里连续浏览所有设置页。

## 录制与导出

建议使用 OBS 的窗口采集，只采 VeraAgent 窗口；画布与输出统一为 1920×1080、30 fps，避免把高分辨率小字直接缩成不可读画面。采用简单输出模式的高质量录制，有可用硬件编码器时可选用。上述分辨率和时长是本项目的制作建议。

先录 MKV，结束后用“文件 → 录像转封装”得到 MP4；这是 [OBS 官方录制指南](https://obsproject.com/kb/standard-recording-output-guide)支持的流程，MKV 在录制异常中更能保全素材。字幕建议独立保存为 SRT；官网默认静音可播放，关掉声音也应能看懂主线。

保留三份成品：完整母版、90 秒 MP4（H.264，兼容播放）、同内容的 WebM。网页建议目标控制在约 15–25 MB，若文字开始模糊则优先保清晰度，再缩短片长。封面取“测试通过 + 可见工作站”的真实画面；录制后人工核对字幕、命令和剪辑顺序。

## 替换落地页素材

现状：官网首页第二屏是工作站静态截图；演示页与 README 使用旧的预设流程视频，不是本次新增功能的真实模型录像。当前素材应继续保留其“预设流程”说明，直到新实录完成。现有 `workstation-no-right-panel.png` 中还能看到“模型列表加载失败”，正式推广前应在模型列表正常加载后重新截取该图，新视频与封面也采用正常连接状态。

新素材就绪后更新：

- `website/assets/video/`：加入新文件与封面，建议采用 `veraagent-real-task-demo.mp4`、`veraagent-real-task-demo.webm`、`real-task-poster.jpg`。
- `website/playground/index.html`：替换 `<video>` 的 source/poster/aria-label，MP4 与 WebM 分别提供正确 MIME 类型。
- `website/assets/site.js`：同步中英文视频说明；实录注明“真实模型操作，等待片段已加速”，保留实际提供商、模型名称和录制日期。
- `README.md`、`README_zh-CN.md`：替换预览链接与封面。若首页也嵌入新实录，再更新 `website/index.html`。
- `website/content/home.md`、`website/content/playground.md` 和对应英文内容：同步“实录”与“预设流程”的描述。
- 运行 `python website/check_site.py`，再在浏览器验证播放、暂停、拖动、静音、移动宽度及中英文说明。

不要将“守护用例通过”剪成“系统保证持续变强”；在线监控是用户触发的前后评分比较，不是后台定时进化。外部模型仍接收提示词和选定上下文，本地存储不表示离线模型推理。
