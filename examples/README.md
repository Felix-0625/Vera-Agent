# Examples

These examples are small, reviewable starting points, not production integrations or trusted marketplace packages.

- [`sample-project/`](sample-project/README.md): a project folder with a concise `AGENTS.md` rule file. Bind this folder in the desktop app to see project-level instructions in context.
- [`mcp-server/`](mcp-server/README.md): a standalone stdio MCP server with three diagnostic tools and a local protocol smoke client.

Review example code before running it. The MCP server runs with the current user's permissions and is not sandboxed.
