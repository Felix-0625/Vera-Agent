# Vera Agent，你的个人工作站

让任务、对话、专业角色和工作流在同一个本地工作站里协作。

VeraAgent 面向软件项目：绑定一个本地目录，交给 Vera Agent 处理任务；需要分工时，可以调用子智能体，或使用自行设计的组织架构和工作流。工具调用、审批、节点结果与最终答复都能回到项目上下文中查看。

**按钮：** [在 GitHub 查看源码](https://github.com/Felix-0625/Vera-Agent)

## 工作站的核心

### 组织由你定义

为项目设定角色、职责和上下级关系。组织架构是一棵汇报树：每个角色有明确的上级，任务与结果按关系传递。它不是一组固定的人设卡片。

### 流程由你编排

从模板创建项目实例，在可视化编辑器中连接步骤，设置条件和循环。运行时每个节点拥有独立会话；当前调度按节点顺序执行，结果经过最终复核后回到发起对话。

### 过程可以核对

对话中的工具请求、审批、返回结果以及工作流节点状态都有可观察记录。项目任务看板可关联对话；任务状态由用户明确更新，不因为 Agent 回复就自动变成“完成”。

## 评测与 RSI

从低分记录生成规则或 Skill 提案，对照评测后由用户采纳，并监测效果与回滚条件。详细机制见[系统设计](design/index.md)和[日常使用](docs/usage.md)

## 完成安装后，一条命令开启工作站

在 Windows 上按[快速开始](docs/quick-start.md)完成源码与依赖安装后，从仓库根目录运行：

```powershell
.\start-desktop.ps1
```

打开应用后，在 **设置 → 模型** 配置自己的模型，再绑定项目。当前发布方式是 GitHub 源码，不提供签名安装包或自动更新。
