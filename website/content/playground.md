# 演示视频

通过一条预设任务，查看 VeraAgent 工作站中的任务、对话、角色分工、节点状态和结果回传如何呈现。

当前页面播放此前预设演示界面的录屏。原演示由本地 JavaScript 预设数据驱动，**不会**调用真实模型、桌面后端或访客的本地文件；视频中的工具调用与运行轨迹仅用于说明交互方式，不是一次真实执行的证据。新版真实任务实录按[录制脚本](../../docs/DEMO_RECORDING.md)准备，完成前保留现有说明。

## 演示路径

1. 查看项目任务和发起对话。
2. 观察任务如何分给不同职责的协作角色。
3. 查看预设的节点状态、输入摘要和结果。
4. 回到原对话阅读汇总，理解“结果返回工作站”的体验。

要在自己的项目中运行真实流程，请按[Windows 快速开始](docs/quick-start.md)启动桌面应用，并使用[组织与工作流指南](docs/usage.md#自定义组织与工作流)创建项目实例。
