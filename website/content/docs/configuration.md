# 配置与本地数据

桌面应用的主要设置从 **设置** 面板完成。环境变量主要供启动、开发和 Python CLI 使用；完整清单见[环境变量表](environment-variables.md)。

## 模型与凭据

在 **设置 → 模型** 添加服务商、模型名、接口地址和 API Key，并选择默认模型。部分参数（上下文窗口、输出上限、采样参数、工具调用上限）可按模型能力调整。模型密钥保存在应用级 `.agents/models_config.json`，**未加密**；API 响应不会返回密钥。请避免把该文件提交到 Git 或作为演示数据分享。

## 项目与会话

绑定项目时，工作站记录本地目录路径，并在项目的 `.agents/` 中保存会话、组织/工作流实例、运行和定时任务。绑定不会复制项目，也不意味着命令只能访问该目录。项目文件和 Git 状态仍在原目录。

## 权限

设置可分别控制默认模式、需要审批的动作类别、操作范围和工具重试次数。类别包含读取、创建、编辑、终端、搜索、MCP 与委派。批准提示应显示对应工具动作；实际能否执行以服务端权限检查为准。“仅项目”是应用路径策略，**不是 Windows 系统沙箱**。终端以当前用户身份运行。

## MCP 与 Skill

MCP 服务与 Skill 安装/启停当前属于应用级设置。外部 MCP 服务器可能启动进程或连接网络；Skill 是可影响 Agent 行为的指令包。市场条目只提供发现入口，不代表签名、安全审核或项目级隔离。启用前检查来源、执行命令、脚本、环境变量和网络访问。

## 数据位置与备份

| 数据 | 桌面启动时的位置 | 示例内容 |
| --- | --- | --- |
| 应用级 `.agents/` | `<checkout>/vera-agent/.agents/` | 模型、权限、MCP/Skill、模板、任务看板 |
| 项目级 `.agents/` | `<project>/.agents/` | 会话、项目实例、运行、定时任务 |
| WebView2 浏览器数据 | `%LOCALAPPDATA%\VeraAgent\WebView2` | 桌面窗口浏览器数据 |
| CLI `.env` | `VERA_GLOBAL_CONFIG_DIR`，默认平台用户配置目录 | Python CLI 兼容设置 |

任务看板工作项存于应用级 `taskboard.sqlite`，并通过 `project_id` 关联项目。项目会话和工作流运行记录是本地文件；当前没有自动云同步。**备份前先关闭 VeraAgent**，再复制相关 `.agents/` 目录。文件布局和记录字段见[数据模型](../../../docs/DATA_MODEL.md)。

## 学习功能的设置与备份

应用级 `.agents/` 新增 `traces.db`、`memory.db`、`telemetry_config.json`、`memory_config.json`、`evolution_config.json`、`evals/` 和 `evolution/`。数据库内含对话摘录、工具参数、作用域记忆与历史，备份时一并复制；分享日志前仍应人工检查脱敏结果。

默认启用本地轨迹；Langfuse 导出、Mem0 和模型记忆整理默认关闭。默认记忆预算 150、用户规则预算 120，已采纳规则独立应用；门禁默认每个用例每个配置重复 3 次。配置字段与费用边界见[学习闭环](../../../docs/LEARNING_LOOP.md)。
